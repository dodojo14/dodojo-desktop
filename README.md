# dodojo for Mac

下载最新版本：

- **Apple 芯片**（M1、M2、M3、M4…）：[dodojo-mac-apple-silicon.dmg](https://github.com/dodojo14/dodojo-desktop/releases/latest/download/dodojo-mac-apple-silicon.dmg)
- **Intel 芯片**：[dodojo-mac-intel.dmg](https://github.com/dodojo14/dodojo-desktop/releases/latest/download/dodojo-mac-intel.dmg)

不确定是哪种芯片：点屏幕左上角  →「关于本机」，看「芯片」或「处理器」那一行。

安装：打开 DMG，把 dodojo 拖进「应用程序」，再从「应用程序」里打开。之后有新版本时 dodojo 会自动下载，并提示你重启。

这个仓库只放安装包和自动更新信息，不包含源代码。
